# เพื่อน Auto Battler

เกมจัดทีมแนว TFT ธีมเพื่อน · เล่นคนเดียวกับบอต หรือออนไลน์กับเพื่อน (สูงสุด 8 บ้าน)

เปิดเล่น: `https://<ชื่อผู้ใช้ GitHub>.github.io/<ชื่อ repo>/`

## เล่นออนไลน์
1. คนหนึ่งกด **ออนไลน์ → สร้างห้อง** แล้วส่งรหัสห้อง 4 ตัวให้เพื่อน
2. เพื่อนกด **ออนไลน์** ใส่รหัส แล้วกด **เข้าห้อง**
3. เจ้าของห้องเลือกจำนวนบอต แล้วกด **เริ่มเกม**

- เครื่องเจ้าของห้องเป็นตัวกลาง ต้องเปิดเกมค้างไว้จนจบ ถ้าปิดไปเกมจะหยุด
- เพื่อนที่หลุดหรือรีเฟรช ให้เข้าห้องรหัสเดิมด้วยชื่อและรหัส 4 หลักเดิม จะกลับเข้าบ้านเดิมได้ภายใน 30 วิ หลังจากนั้นบอตจะเล่นแทน
- เครื่องต่อหากันตรง ๆ (WebRTC ผ่าน PeerJS) ไม่มีเซิร์ฟเวอร์เกม ถ้าเน็ตบางที่ต่อไม่ติด (Wi-Fi ที่ทำงาน หรือเน็ตมือถือบางเจ้า) ลองเปลี่ยนเน็ตดู

## อัปเดตเกม
อัปโหลด `index.html` กับ `assets-1.js`…`assets-4.js` ชุดใหม่ทับของเดิม แล้วรอ 1–2 นาที
